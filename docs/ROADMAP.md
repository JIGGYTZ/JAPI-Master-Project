# Roadmap

## 1. Close the private prototype baseline

- preserve one authoritative version;
- complete reproducible build and release gates;
- maintain access, security, browser and recovery evidence;
- keep unsupported functions disabled.

## 2. Validate the beachhead problem

- conduct structured interviews with users, buyers, approvers and domain supervisors;
- separate evidence from assumptions;
- select one narrow workflow based on verified need.

## 3. Design a bounded pilot

- identify a willing host and responsible owner;
- define consent, privacy, safety and stop conditions;
- establish baseline measures and independent evaluation;
- obtain real quotations and a costed operating plan.

## 4. Run only after approval

- use human approval for consequential actions;
- record provenance, decisions, failures and outcomes;
- issue a go, revise or stop decision.

## 5. Scale only from evidence

- refine the product and business model from verified results;
- complete legal, IP, security and operational requirements;
- expand only where value, safety and support capacity are demonstrated.
