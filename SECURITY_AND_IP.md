# Security and IP Boundary

This repository is a public project overview, not the JAPI source repository.

## Intentionally excluded

- private source code and architecture details;
- credentials, tokens, environment files and deployment secrets;
- private datasets or personal information;
- hidden evaluators, adversarial cases and proprietary benchmark logic;
- attorney-client or confidential legal materials;
- unapproved production packages.

## Responsible disclosure

Do not post suspected security vulnerabilities publicly. Contact the project owner privately through the contact channel listed in the Future Caribbean application or public project profile.
